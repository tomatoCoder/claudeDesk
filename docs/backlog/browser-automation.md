# 浏览器后续能力待办

第一版仅提供页面预览、元素/文字标注、评论驱动修改和刷新复核。以下能力延后实现：

- Agent 自动点击、输入、滚动和页面流程执行。
- 页面截图、区域截图及视觉分析。
- DOM 与可访问性树快照。
- CDP 网络、控制台、性能和运行时诊断。
- 自动复现、修改、刷新并验证问题的闭环。
- 多标签页、下载、书签和历史管理。
- 跨页面、跨任务及重启后持久化的标注。

扩展时复用 `BrowserManager`、独立的 `persist:claude-desk-browser` session，以及 `BrowserAnnotation` 契约。远程页面只允许使用标注专用 preload，绝不能获得通用应用 IPC、文件系统、Node.js 或 Claude 执行权限。
