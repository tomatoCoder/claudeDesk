# 双平台安装与最小闭环验收清单

候选安装包生成后，必须在对应的真实系统上逐项验证。自动化测试通过不能替代本清单。

## macOS 13+ Apple Silicon

- 打开 `.dmg`，将 Claude Desk 拖入 Applications，并能按未签名应用提示首次启动。
- 已加入 PATH 或安装在常见位置的原生 `claude` 能被识别，版本低于 `2.1.223` 时显示明确错误。
- 未安装或不可执行时，界面显示修复说明并允许重新检测。
- 自动发现 Claude 历史项目和会话；手动添加包含空格、中文的项目目录也能成功。
- 打开历史会话后加载消息，继续发送时沿用原会话模型。
- 新建会话后使用当前 `ANTHROPIC_MODEL`，发送消息并持续展示流式文本、Markdown 和代码块。
- 工具调用有开始/完成状态；允许、拒绝和 `AskUserQuestion` 均能恢复对应轮次。
- 同一会话运行时不能重复提交；两个不同会话可以并行，切换侧边栏不会中断执行。
- 停止响应后，Bridge 和 Claude 子进程退出，界面状态为已中断。
- 会话可重命名；删除前显示二次确认，确认后 transcript 与附属目录进入废纸篓，项目源码不受影响。
- 设置页正确读写三个受管 `env` 值，Token 默认掩码；未知 JSON 字段保持不变，并生成备份。
- 外部修改 `settings.json` 时，干净表单自动刷新；存在未保存编辑时显示冲突且不静默覆盖。
- 有活动轮次时关闭应用出现确认；取消则保持运行，确认则终止本应用启动的进程。
- 重启应用后，遗留的运行状态被恢复为已中断，历史消息仍可读取。

## Windows 10 1809+ x64

- NSIS 以当前用户安装和卸载，不要求管理员权限。
- PowerShell/CMD 可用或位于常见安装位置的原生 `claude.exe` 能被 GUI 识别；不依赖 WSL。
- 含空格、中文与较长路径的项目可以发现、添加、打开和运行。
- 重复执行 macOS 清单中的会话恢复、新建、流式消息、权限、并行、停止、重命名、删除和设置同步场景。
- 停止或确认退出后，通过任务管理器确认没有残留的 Claude Desk Bridge/Claude 子进程。
- 删除会话进入回收站；卸载只移除应用，不删除项目目录、Claude CLI、Claude 设置或历史会话。
- 未签名安装包出现 SmartScreen 时，来源确认后的“仍要运行”路径可用。

## 安全与范围边界

- Vue 前端只有结构化 Tauri IPC 和文件夹选择权限，没有 shell execute/spawn 权限。
- 提示词、Token 和路径不拼接到 shell 命令字符串；Bridge 只接收结构化 JSONL。
- 最终安装包内包含 Agent Bridge sidecar，但不包含或下载 Claude CLI。
- Bridge 协议版本、请求 ID、运行 ID 和事件序号均被校验；输出有大小限制且错误会脱敏。
- 权限请求在超时、连接断开、停止或退出时默认拒绝。
- `settings.json` 非法时阻止写入；写入使用临时文件替换，并保留时间戳备份。
- 会话删除只允许 Claude 数据根目录下完整 UUID 的精确目标，并使用废纸篓/回收站。
- 产品界面没有终端、Git Diff、代码审查、MCP 管理、登录或更新入口。
