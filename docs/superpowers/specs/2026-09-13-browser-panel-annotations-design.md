# 右侧浏览器面板与批注模式设计

## 目标

将现有独立原生浏览器窗口改为 Claude Desk 主窗口右侧的浏览器面板。会话顶部增加与“文件”同级的“浏览器”按钮；浏览器面板提供地址栏、刷新、关闭及右上角批注开关。批注模式下，用户点击网页元素或选择文字，即可填写评论，评论以网址、选中内容和评论文本的格式追加到当前会话草稿，不自动发送。

## 用户体验

1. 当前会话顶部的“浏览器”按钮与“文件”按钮并列，显示 `Cmd/Ctrl+T` 快捷键提示。
2. 点击按钮或快捷键后，右侧展开可拖拽宽度的浏览器面板；再次点击或关闭按钮收起面板。
3. 面板首屏显示地址输入。提交有效 HTTP(S) 地址后，原生网页视图载入页面；地址栏保留当前地址，并可刷新、重新导航。
4. 工具栏最右为“批注”切换按钮。未开启时网页保持正常浏览行为。
5. 开启批注后，鼠标悬浮到可见元素时显示淡蓝色边框；点击元素后显示蓝色边框、圆点标记和轻量评论输入条。若用户先拖选文字，则批注关联该段文字而非整个元素。
6. 填写并提交评论后，当前会话输入框追加：评论、网页 URL、选中文本（或元素可读文本）。取消、Escape 或关闭批注模式均清除当前临时标记。

## 架构

远程网站不能依赖 iframe：常见页面会因嵌入策略拒绝载入。因此主窗口保留本地 Vue 界面，Tauri 在同一原生窗口中创建一个标签为 `browser-panel` 的 child WebView，并按 Vue 面板尺寸定位、调整大小和显隐。

Vue 的 `BrowserPanel` 仅管理本地工具栏、尺寸和状态；Rust 的浏览器命令负责 child WebView 的创建、导航、边界更新和销毁。child WebView 加载外部 HTTP(S) 页面，通过初始化脚本实现批注模式。脚本只能调用 `browser_comment`，由后端转发 `browser-comment` 事件给主 WebView。外部网页不可调用文件、项目、任务、Shell 或对话框命令。

## 组件与接口

- `App.vue`：维护 `browserOpen`、宽度和快捷键；与现有 Files 抽屉同级渲染 `BrowserPanel`，在窗口 resize、面板 resize/open/close 时通知 Rust 更新 child WebView bounds。
- `BrowserPanel.vue`：本地面板标题栏，含地址输入、刷新、批注切换、关闭和拖拽手柄；不通过 iframe 渲染网页。
- `browserPanel` 前端服务：`openBrowserPanel(url?)`、`resizeBrowserPanel(bounds)`、`setBrowserAnnotationMode(enabled)`、`closeBrowserPanel()`，以及 URL 规范化与草稿格式化。
- `commands::browser`：将当前独立 `browser` 窗口替换为主窗口 child WebView；公开创建/导航、bounds、显示、批注开关和关闭命令。
- `browser-panel` capability：仅针对 child WebView 标签及远程 HTTP(S) URL，且只允许 `browser_comment`。

## 批注脚本

- 初始化脚本持有 `annotationMode`，默认关闭；本地命令通过 WebView `eval` 切换该值。
- 开启时用事件委托监听 `mousemove`、`click` 与文字选区，注入 Shadow DOM 覆盖层。覆盖层不改变宿主页面 DOM 内容、布局或链接行为。
- 元素评论读取 `innerText` 的规范化前 20,000 字符；文字评论优先读取 `window.getSelection()`。
- 评论框支持取消、Escape 和 `Cmd/Ctrl+Enter` 提交。普通 Delete/Backspace 只在输入框内编辑，绝不关闭面板或清空浏览器。
- 关闭模式、导航或收起面板时，脚本移除覆盖层、浮标和输入框。

## 布局与窗口管理

- 右侧面板默认宽 680px，最小 420px、最大 960px，宽度保存至 `localStorage`，与文件抽屉一致。
- child WebView bounds 从主窗口客户区减去应用顶部尺寸和浏览器面板工具栏尺寸计算；在主窗口尺寸变化、面板宽度变化或状态变化时更新。
- 打开新地址时复用唯一 `browser-panel` WebView。关闭面板时隐藏 child WebView；不销毁会话中的当前页面，重新打开后恢复它。
- 同时打开文件与浏览器时，二者在右侧依次排列，浏览器在最右；若窗口不足，面板采用绝对覆盖布局，保证任何时刻只有一个远程 child WebView 可见。

## 错误与安全

- 地址为空、无效、超长或非 HTTP(S) 时，在面板地址栏显示错误且不导航。
- 未选择会话时仍可浏览；提交评论时主窗口显示“请先选择会话”，不误写入别的任务。
- child WebView 的评论 payload 受到 URL 4096、选中文本 20,000、评论 4,000 字符限制，后端再次校验。
- 注入失败或网页不允许选区时不影响正常浏览；批注开关关闭并显示轻量错误。

## 验收

- 会话顶部存在“浏览器”按钮，行为、尺寸和关闭方式与“文件”一致。
- URL 能在右侧原生面板载入，而非弹出独立窗口或 iframe。
- 批注开关控制元素高亮与评论框；关闭时不拦截网页正常交互。
- 提交评论在当前输入框中追加网址、选中文本/元素文本和评论，不自动发送。
- 浏览器远程页面只具有 `browser_comment` 权限；原有主窗口命令不受影响。
- 文件编辑和评论中的 Delete/Backspace 不会关闭抽屉；浏览器评论输入同样正常工作。

## 非目标

- 不加入多标签、历史、书签、下载或持久化网页评论。
- 不上传整页内容、Cookie、认证信息或网页脚本到会话。

## 2026-09-13 修复补充

- 浏览器挂在应用持久布局中，切换任务、项目或设置不卸载。显式关闭仅隐藏原生页面，再次打开复用页面。
- 标题与导航地址栏分为两行。浏览器宽度受剩余窗口空间约束；打开浏览器时收起文件面板，之后打开文件时限定在左侧工作区内。
- 原生视图一次性更新完整边界，前端串行合并更新并在 DOM 布局完成后测量。macOS 的顶部原生空隙单独保留，不能用高度比拉伸 CSS 坐标。
- 创建原生 WebView 使用异步命令。网页开始/完成事件更新加载反馈及跳转后的地址；超时显示可重试错误。
- 新增后退、前进，本地 localhost/127.0.0.1/IPv6 回环地址无协议时使用 HTTP。
