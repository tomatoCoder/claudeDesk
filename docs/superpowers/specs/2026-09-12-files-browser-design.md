# Claude Desk Files 侧边栏设计

## 1. 背景与目标

Claude Desk 当前只能通过附件按钮、拖拽或剪贴板把已知文件路径加入消息，缺少像 Codex `Files` / `Cmd+P` 一样浏览当前项目并预览文件的能力。

本功能在任务页右上角增加 `Files` 入口，并提供 `Cmd+P`（Windows 为 `Ctrl+P`）快捷键。入口打开右侧 Files 抽屉；对话区始终保留，正在运行的任务不被中断。用户可筛选项目文件、展开目录树并在抽屉内预览文件。

## 2. 范围

### 2.1 包含

- 顶栏右上角 `Files` 按钮与键盘快捷键。
- 从工作区右侧滑出的可调整宽度抽屉。
- 懒加载目录树和按路径筛选文件。
- 文本文件源码预览，包含面包屑、行号、复制按钮和语法高亮。
- Markdown 源码/渲染预览切换。
- 常见图片格式预览。
- 二进制文件、超大文件和读取失败的明确状态。
- macOS 和 Windows 路径安全校验。

### 2.2 不包含

- 编辑、保存、重命名、移动或删除项目文件。
- Git diff、审查、暂存或提交操作。
- 在 Files 面板中添加消息附件。
- 全文内容搜索；筛选只匹配文件或目录路径。
- 文件系统实时监听。用户可重新打开、刷新或切换项目获取最新目录。

## 3. 用户体验

### 3.1 打开与关闭

- 仅在存在已选项目和任务时显示顶栏 `Files` 按钮。
- 点击按钮或按 `Cmd+P` / `Ctrl+P` 打开 Files 抽屉，并聚焦“筛选文件…”输入框。
- 抽屉已打开时再次触发快捷键，只聚焦并全选筛选文本，不关闭抽屉。
- `Escape` 的优先级为：有筛选文本时先清空；筛选为空时关闭抽屉。
- 顶栏按钮显示打开状态；抽屉标题栏提供显式关闭按钮。
- 切换任务但项目不变时保留抽屉和当前文件；切换项目时清空选择并加载新项目根目录。

### 3.2 布局

- 桌面宽度下，抽屉从右侧进入并占工作区约 45%，默认宽度 720px，限制在 520–960px。
- 抽屉左边缘提供拖拽调整宽度；尺寸只在当前应用会话内保留。
- 对话区与抽屉并排布局，对话滚动位置和 Composer 状态不变。
- 当工作区宽度不足 960px 时，抽屉覆盖在对话区之上，宽度为 `min(92vw, 720px)`，避免压缩对话到不可用尺寸。
- 抽屉内部默认只显示文件树。选择文件后分为预览区和约 300px 的文件树区；空间不足时文件树保持 260px，预览区横向滚动。

### 3.3 文件树与筛选

- 根目录显示当前项目名；目录可展开/折叠，条目按“目录优先、名称不区分大小写”排序。
- 初次打开只读取根目录；展开某个目录时才加载它的直接子项。
- 未筛选时展示懒加载树，包括隐藏目录和被忽略目录的顶层入口，但 `.git` 内部不允许展开。
- 输入筛选文本后切换为扁平搜索结果，匹配项目相对路径，文件名匹配优先于路径匹配。
- Git 项目的搜索索引来自 `git ls-files --cached --others --exclude-standard`，因此不扫描 `.git`、`node_modules` 等被忽略内容；非 Git 项目递归扫描时跳过 `.git`、`node_modules`、`target` 和 `dist`，最多返回 200 项。
- 支持键盘上下选择、左右展开/折叠、Enter 打开文件。
- 空结果、加载中和加载失败均在树区域原位展示。

### 3.4 文件预览

- 选择文件后，预览标题显示项目相对路径面包屑，并提供复制文件内容、刷新和关闭当前预览操作。
- UTF-8 文本以只读源码展示，固定宽度字体、行号和按扩展名选择的语法高亮；长行保持横向滚动，不自动折行。
- Markdown 默认显示源码，并提供“查看预览 / 查看源码”切换；渲染复用现有 Markdown 清洗管线，不执行 HTML 脚本。
- PNG、JPEG、GIF、WebP、BMP 和 SVG 以图片模式展示。SVG 必须经过安全处理或以隔离图片资源显示，不作为可执行 HTML 注入。
- 包含 NUL 字节或无法解码的内容视为二进制，仅展示名称、类型和大小。
- 文本及图片读取上限为 2 MiB；超过限制时不传输内容，只显示文件大小和“文件过大，无法预览”。
- 文件在预览期间发生变化时，用户点击刷新重新读取；首版不自动监听。

## 4. 架构与数据流

### 4.1 Rust 文件边界

新增独立的项目文件读取模块，不复用 Git diff 模块。所有命令先通过 `projectId` 从存储层取得项目根目录，再处理前端提供的项目相对路径。

提供三个 Tauri Command：

1. `list_project_directory(projectId, path)`：返回某目录的直接子项。
2. `search_project_files(projectId, query, limit)`：返回排序后的匹配文件。
3. `read_project_file(projectId, path)`：返回文本、图片字节或不可预览元数据。

公共 DTO：

```ts
interface ProjectFileEntry {
  name: string
  path: string
  kind: 'file' | 'directory'
  extension?: string
}

interface ProjectFilePreview {
  path: string
  kind: 'text' | 'image' | 'binary' | 'too_large'
  mimeType?: string
  content?: string
  bytes?: number[]
  size: number
}
```

目录树只保存相对路径与已加载子项；打开文件时独立调用读取命令。项目切换使用递增请求版本或项目 ID 比对，丢弃旧项目迟到的异步结果。

### 4.2 前端组件

- `App.vue`：持有抽屉开关和宽度，渲染顶栏入口，注册全局快捷键，协调项目切换。
- `FileBrowserDrawer.vue`：抽屉框架、宽度调整、筛选状态、键盘导航和预览/树布局。
- `ProjectFileTree.vue`：懒加载目录节点、扁平筛选结果和选择状态。
- `FilePreview.vue`：文本、Markdown、图片和不可预览状态路由。
- `services/projectFiles.ts`：目录请求缓存、并发去重、筛选请求版本控制和纯排序/匹配工具。
- `services/ipc.ts` 与前后端 DTO：定义类型化命令边界。

组件保持单向数据流：抽屉请求目录或搜索结果，树只发出“展开”和“选择”，预览只消费已读取 DTO 并发出刷新/关闭。

## 5. 安全与性能

- 只接受规范化项目相对路径；拒绝绝对路径、`..`、空路径文件读取和平台前缀路径。
- 对目标执行 canonicalize，并验证结果仍位于 canonical 项目根目录下；指向项目外的符号链接拒绝读取或展开。
- 目录项名称来自文件系统，但不拼成 HTML；预览内容以文本或经过现有 DOMPurify 清洗的 Markdown 渲染。
- 单次目录列表和搜索结果设置数量上限；搜索输入使用约 120ms 防抖，并取消显示旧查询结果。
- 文本/图片读取前检查元数据大小，读取后再次验证上限，防止竞态导致超量 IPC。
- 不向前端暴露项目外绝对路径。

## 6. 错误处理

- 项目目录不存在或失去权限：抽屉保留，显示可重试错误。
- 单个目录读取失败：只在对应节点显示错误，不清空其他已加载节点。
- 文件被删除：关闭该预览并刷新其父目录。
- 非 UTF-8、二进制和超大文件属于受支持状态，不作为全局错误。
- 快捷键在设置页、原生对话框或其他模态框打开时不触发，避免抢占输入。

## 7. 测试与验收

### 7.1 Rust

- 目录列表排序和项目相对路径输出。
- 拒绝绝对路径、`..` 和越界符号链接。
- Git 搜索遵循忽略规则；非 Git 回退扫描遵守目录和结果上限。
- 文本、图片、二进制、非 UTF-8和超大文件分类。
- 文件在元数据检查后变大的读取上限保护。

### 7.2 前端

- 顶栏按钮与 `Cmd+P` / `Ctrl+P` 打开抽屉并聚焦筛选框。
- 快捷键不会抢占设置页或模态框。
- 展开目录只请求一次，失败可重试。
- 筛选结果排序、键盘选择和迟到响应丢弃。
- 选择文件加载预览，不重建或替换 ConversationView。
- Markdown 源码/预览切换，文本复制，图片及不可预览状态。
- 项目切换清空旧状态；任务切换但项目相同时保留状态。
- 桌面并排布局和窄屏覆盖布局的结构断言。

### 7.3 手工验收

1. 在包含大量依赖目录的 Git 项目打开 Files，首屏不出现明显卡顿。
2. 用鼠标和 `Cmd+P` 打开抽屉，筛选并仅用键盘打开文件。
3. 展开目录、预览源码、切换 Markdown 预览并复制内容。
4. 在对话流式输出期间打开、调整和关闭抽屉，确认流式输出与 Composer 内容保持不变。
5. 验证项目外符号链接、二进制文件和超过 2 MiB 文件的受控状态。
6. 在窄窗口确认抽屉覆盖显示且对话可恢复。

完成标准：Files 抽屉的入口、快捷键、筛选、目录树和预览行为与确认截图的核心工作流一致，同时不替换、不重建也不中断当前对话。
